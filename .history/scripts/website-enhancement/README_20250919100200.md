# 网站增强工具

这个分类包含各种网站功能增强脚本，帮助改善用户的网页浏览体验。

## 脚本列表

### 页面美化助手 v2.0.0

**功能描述**：全新升级的高级页面美化工具，提供丰富的网页个性化功能，支持动画交互、可拖拽界面、网站独立配置等特性

**适用网站**：
- 全网站通用支持
- 针对不同网站提供独立配置存储
- 特别优化新闻、博客、论坛等内容网站

**🌟 核心功能**：

**🎨 基础美化**
- 🌙 **暗黑模式**：一键切换暗黑/明亮模式，保护眼睛健康
- 🅰️ **字体调节**：10-30px字体大小自由调节，支持实时预览
- 📚 **阅读模式**：优化版式布局，提供舒适的阅读体验
- 🚫 **广告屏蔽**：智能识别并隐藏各种广告元素
- 🖼️ **图片隐藏**：专注文字内容，可选择隐藏所有图片

**✨ 高级功能**
- 🌫️ **背景模糊**：为页面添加时尚的模糊背景效果
- 🎯 **专注模式**：鼠标悬停高亮，提升阅读专注度
- 📊 **页面缩放**：50%-200%自由缩放，适应不同屏幕
- 📐 **行高调节**：1.0-3.0倍行高设置，优化文字密度
- 🎨 **颜色方案**：多种滤镜效果（暖色调、冷色调、黑白、复古）
- ⚙️ **自定义CSS**：支持高级用户输入自定义样式代码

**🚀 交互特性**
- **可拖拽按钮**：控制按钮支持自由拖拽定位
- **可拖拽面板**：设置面板支持拖拽移动
- **动画效果**：丰富的过渡动画和视觉反馈
- **智能隐藏**：右键控制按钮可快速隐藏/显示
- **响应式设计**：适配各种屏幕尺寸

**⌨️ 快捷键支持**
- `Alt + B`：切换控制按钮显示/隐藏
- `Alt + D`：快速切换暗黑模式
- `Alt + R`：快速切换阅读模式
- `Alt + S`：打开设置面板
- `Esc`：关闭设置面板

**💾 数据管理**
- **网站独立配置**：每个网站的设置独立保存
- **配置导出**：支持导出设置为JSON文件
- **配置导入**：支持导入之前保存的设置
- **一键重置**：快速恢复默认设置

**安装方法**：
1. 点击 [安装链接](https://raw.githubusercontent.com/Lee-zg/qmsl/main/scripts/website-enhancement/page-beautifier.user.js)
2. 确认安装
3. 访问任意网站即可使用

**使用说明**：
1. 脚本会在页面显示一个可拖拽的控制按钮 🎨
2. **左键点击**按钮打开设置面板
3. **右键点击**按钮快速隐藏/显示
4. **拖拽按钮**可移动到任意位置
5. **拖拽面板标题栏**可移动设置面板
6. 使用快捷键快速切换常用功能

**界面特色**：
- 🎨 **现代化设计**：渐变背景、圆角设计、阴影效果
- 🎭 **动画交互**：流畅的过渡动画和悬停效果
- 📱 **响应式布局**：完美适配不同屏幕尺寸
- 🛡️ **防干扰设计**：界面元素不受网站样式影响
- 🌈 **主题支持**：多种配色方案和视觉效果

**技术亮点**：
- 🔄 **实时生效**：所有设置变更无需刷新页面
- 🎯 **精准控制**：支持细粒度的样式调节
- 💽 **本地存储**：配置数据安全保存在本地
- 🔍 **智能检测**：自动监测页面变化并应用设置
- ⚡ **高性能**：优化的DOM操作，不影响页面性能
