# 网站增强工具

这个分类包含各种网站功能增强脚本，帮助改善用户的网页浏览体验。

## 脚本列表

### 页面美化助手 v1.1.0

**功能描述**：为网页添加暗黑模式、字体调节、阅读模式、广告屏蔽等美化功能

**适用网站**：
- 通用网站支持
- 特别优化常见新闻、博客网站
- 支持不同网站独立配置

**主要功能**：
- 🌙 **暗黑模式**：一键切换暗黑/明亮模式，保护眼睛
- 🅰️ **字体调节**：自定义字体大小(10-30px)，支持实时预览
- 📚 **阅读模式**：优化阅读版面布局，提升阅读体验
- 🚫 **广告屏蔽**：智能识别并隐藏各种广告元素
- ⚙️ **自定义CSS**：支持输入自定义CSS代码
- 🎯 **网站独立配置**：每个网站的设置独立保存
- 🔄 **一键重置**：快速恢复默认设置
- 📤 **设置导出**：支持导出配置文件

**安装方法**：
1. 点击 [安装链接](https://raw.githubusercontent.com/Lee-zg/qmsl/main/scripts/website-enhancement/page-beautifier.user.js)
2. 确认安装
3. 访问任意网站即可使用

**使用说明**：
1. 脚本会在页面右上角添加一个控制按钮 🎨
2. 点击按钮可以打开设置面板
3. 调整各项设置后点击“应用设置”即时生效
4. 支持Tampermonkey菜单快捷访问

**亮点特性**：
- ✨ **防干扰设计**：控制按钮和设置面板样式不受网站影响
- 🚀 **实时生效**：设置变更无需刷新页面
- 🎨 **精美界面**：现代化设计，支持渐变背景和动画效果
- 🔒 **数据安全**：每个网站的设置独立存储，互不影响
- 🔍 **智能监控**：自动监测页面变化，实时应用设置
